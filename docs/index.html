What you see when you open a locked app

See it in action

27 seconds: open a locked app, get it wrong, get it right, and lock a new one.

Simple, and does the one job well

No accounts, no cloud, no subscription. AppLock runs on your PC and stays out of the way until a locked app is opened.

Master or per-app passwords

Use one master password for everything, or give a specific app its own password.

Pick from your installed apps

Choose from a searchable list of your apps with their icons, or browse for any .exe.

One prompt per launch

Works with apps that run many processes, like Discord, Chrome and Steam. You're asked once, not over and over.

Slows down guessing

After a few wrong passwords, each new try has to wait a little longer.

Passwords never stored

Only salted PBKDF2 hashes are saved, in a settings file normal users can't change.

Clean uninstall

Uninstalling removes every lock and the background service. Nothing is left behind.

How it works

Set it up once in about a minute.

Install and set a master password

Run the installer, open AppLock from the Start menu, and choose your master password.

Lock the apps you want

Click Lock an app…, pick it from your installed apps, and choose which password unlocks it.

Open apps as usual

Locked apps ask for the password first. The right password opens the app; anything else keeps it closed.

Good to know

AppLock keeps casual snoopers out. It isn't a substitute for a separate Windows account.

  • Locks by file name. Renaming or copying a program's .exe gets around the lock.
  • Admins can undo it. Anyone with administrator rights on the PC can remove locks.
  • Microsoft Store apps aren't supported. Classic desktop programs work.
  • Stays unlocked while running. An app that's still open (including in the system tray) won't ask again until it fully closes.

Questions

Windows says "Windows protected your PC". Is that normal?

Yes. The installer isn't code-signed yet, so SmartScreen doesn't recognise it. Click More info, then Run anyway. The full source code is on GitHub if you'd like to check it or build it yourself.

I forgot my master password. What now?

Uninstall AppLock from Settings → Apps. That removes every lock, so all apps open normally again. Then reinstall and set a new password.

Do I need to install .NET?

No. Everything AppLock needs is included in the installer.

Does AppLock send anything over the internet?

No. AppLock works entirely on your PC and never connects to the internet.
